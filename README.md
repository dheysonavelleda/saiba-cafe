# Saiba Café

Hub de notícias do café. Sempre com a fonte citada.

## Páginas

- `index.html`: home, o hub
- `launch.html`: a jornada do grão, do inteiro ao macro
- `blog/`: índice de matérias e o conteúdo editorial

## Estrutura

- `style.css` e `script.js`: base compartilhada entre as páginas
- `assets/`: imagem do grão, selo do roundel e artes do blog

## Rodar local

Qualquer servidor estático apontando para esta pasta resolve. Em dev, na raiz do projeto maior:

```
node server.js
```

## Deploy

Vercel, projeto `saiba-cafe`. Push na `main` = deploy.
